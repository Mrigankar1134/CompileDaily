GitHub setup guide

1. Create your account & a repo
Go to github.com → sign up (or sign in) → "New repository" → name it (e.g. java-career-prep) → keep it Public so it's visible to recruiters.

2. Install Git & connect your machine
Install Git from git-scm.com. Then, inside your project folder:
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main

3. One repo (or folder) per milestone project
Either create a fresh repo per module's project, or one folder per module inside a single monorepo — whichever is easier to keep organized.

4. Submit a milestone
Once a module's project is pushed, copy its GitHub URL (the repo link, or a specific PR/commit) and paste it into that module's "Milestone project" box in the Roadmap tab — that's what marks the milestone complete here.

5. Keep it recruiter-ready
Add a README to every repo (setup steps, what it does, tech stack). Modules 42 (Technical Documentation) and 43 (Portfolio Development) cover this in depth.
